# OronBox 隐私说明

版本：`1.0.0`  
生效日期：`2026-07-19`

## 1. 适用范围

本说明适用于 OronBox 项目维护者提供的官方在线服务，不适用于用户自行部署的 OronBox Server，也不替代 BandBBS、GitHub、Cloudflare 或其他第三方的隐私说明

## 2. 我们处理的信息

使用 BandBBS OAuth 登录时，官方服务会处理米坛用户 ID、用户名、头像、授权范围以及完成登录所需的 OAuth 凭证

启用米坛发布时，会另行处理发布所需的授权凭证、目标分区、资源 ID、附件和发布状态，普通登录授权不等于米坛发布授权

使用自己的 GitHub 账号发布 AstroBox 资源时，会处理 GitHub 用户 ID、用户名、授权范围、Access Token，以及完成 Web OAuth 所需的一次性 state 和 PKCE 临时校验信息；在 CLI 或无浏览器环境使用 Device Flow 时，还会处理用户代码和对应的临时授权状态

官方服务还会处理 OronBox 会话、客户端平台和版本、IP 地址、User-Agent，以及保障登录、审核和服务安全所需的操作记录

创建资源时，会处理用户主动提交的名称、说明、图片、资源文件、设备绑定、审核记录和外部发布配置

处理权利投诉、安全事件和申诉时，可能处理投诉内容、权利证明、创作者回应、文件哈希、审核意见和与事件直接相关的证据

除法律要求或具体争议确有必要外，OronBox 不主动要求身份证号码、精确住址、生物识别、金融账户、健康信息等与当前服务无关的信息

为节省存储空间，资源文件会按照文件内容计算的唯一特征值去重保存，这种方式称为内容寻址存储，它只影响服务器的物理保存方式，不会使未公开文件对其他用户开放

## 3. 处理目的

这些信息仅用于：

- 登录和维护 OronBox 会话
- 保存、审核、展示和分发资源
- 按用户选择发布到米坛或 AstroBox
- 同步公开资源的下载副本
- 防止滥用、排查故障和处理权利投诉

OronBox 不使用 OAuth 数据投放广告、建立营销画像或出售用户信息

## 4. OAuth 与安全

BandBBS 只读 Access Token 保存在用户设备上，客户端直接用它访问 BandBBS；BandBBS Refresh Token、米坛发布授权 Token 和 GitHub OAuth Token 始终加密保存在 PostgreSQL 中，不会下发给客户端，OronBox 自有会话 Token 在数据库中仅保存不可反向还原的哈希

OAuth Token、Authorization Header、Authorization Code、完整 OAuth 请求体和 OronBox 会话 Token 不得写入普通日志

用户可以撤销 OAuth 授权或退出 OronBox，撤销后停止未来操作，但不会自动删除已经发布到第三方平台的内容和公开历史

BandBBS 登录授权、BandBBS 发布授权和 GitHub 发布授权是相互独立的授权状态

普通 BandBBS 登录不授权 OronBox 创建或修改米坛资源，GitHub 授权也不等于用户已经确认某次具体仓库或 Pull Request 操作

一次性 OAuth state、Authorization Code、登录票据和 GitHub Device Code 只用于完成对应流程，不应作为长期业务数据保存

## 5. 存储地点

OronBox 官方主服务器位于中国香港，账号、OAuth 凭证、会话、草稿、资源、审核记录和本地 Blob 在该服务器处理

通过审核并公开的资源文件和图片会复制到 Cloudflare R2 亚太区域，用作公开下载副本

R2 不是权威存储，不保存 OAuth Token、账号资料、未公开草稿或内部审计日志

Cloudflare 标示的亚太区域不表示数据仅存储于中国香港，R2 的处理和分发仍受 Cloudflare 基础设施及政策约束

用户通过官方在线服务提交的数据会在中国香港处理，公开资源副本可能经 Cloudflare 亚太及全球网络存储和分发

### 内容寻址存储

Blob 指服务器保存的一份文件对象，SHA-256 是根据文件内容生成的固定长度特征值

本地 Blob 按 SHA-256 组织，相同内容可能只保存一份

去重不会让其他用户获得未公开资源的访问权限

删除资源时会移除其对 Blob 的引用，只有在 Blob 不再被其他有效资源、版本、必要证据或备份引用后才能物理删除

## 6. 对外提供和公开

资源发布后，名称、说明、作者名称、图片、文件、支持设备和版本信息会公开提供

用户选择米坛发布时，OronBox 会向 BandBBS 发送完成创建或更新资源所需的内容和身份信息

用户选择 AstroBox 发布时，OronBox 会向 GitHub 和 AstroBox-Repo 提交资源仓库内容、作者名称、Commit 和 Pull Request

公开资源可能被第三方下载、转载或缓存，OronBox 无法删除已经由其他主体保存的全部副本

发生侵权、安全或平台滥用事件时，OronBox 可以按最小必要原则向第三方平台、权利人或相关机构提供资源、外部标识、文件哈希、发布时间和审核记录

IP、User-Agent、设备和会话信息仅在处理账号安全、自动化滥用、封禁规避或其他严重事件确有必要时提供

OronBox 不会常规披露 OAuth Token、会话 Token、与事件无关的草稿或无必要的完整操作历史

已确定的受托服务商包括 Cloudflare, Inc.，用于公开资源副本的存储和网络分发

香港服务器由广州润雨科技有限公司提供，未使用监控、广告或邮件服务时无需虚构相关主体

## 7. 保存和删除

OAuth state 和 PKCE 临时校验信息有效期最长为 10 分钟，OronBox 登录票据有效期最长为 3 分钟，GitHub Device Flow 临时凭证按 GitHub 返回的期限失效

OronBox Access Token 有效期为 15 分钟，Refresh Token 有效期为 30 天，会话轮换、撤销或账号状态变化后可以提前失效

BandBBS 和 GitHub OAuth 凭证原则上保存至用户撤销授权、解绑账号或其不再为相关功能所需

未提交草稿在最后编辑后保留 180 天，用户主动删除草稿时会立即从活跃数据库删除

普通服务端运行日志保留 30 天，安全审计记录保留 180 天，投诉、举报和申诉材料在事件结束后保留 1 年

公开资源、版本、图片和公开元数据在资源公开期间持续保存，已下架资源的必要审核记录在下架后保留 1 年

内容寻址存储可能由多个资源版本共同引用同一 Blob，不再被任何有效资源或必要记录引用的 Blob 经过 7 天宽限期后清理，备份副本最多保留 30 天

用户撤销或解绑 OAuth 授权后，凭证从活跃数据库删除，加密备份副本最多保留 30 天且不得恢复用于新的业务操作

账号注销后，账号资料在 7 天内从活跃数据库删除或匿名化，备份副本最多保留 30 天

备份中的已删除数据不得恢复至生产环境，执行灾难恢复时除外，恢复后应重新执行删除和失效处理

存在未结束投诉、安全事件或法定保存义务时，可以暂停删除相关数据，但仅保留处理事件所必需的最小范围

## 8. 用户请求

用户可以请求查询或更正账号资料、撤销授权、删除未公开草稿，或申请删除不再需要保存的个人信息

已发布至 BandBBS、GitHub 或 AstroBox 的内容需要按照对应平台的机制另行处理

账号注销后应撤销有效 OronBox 会话并停止未来 OAuth 操作，但依法或为处理安全、投诉和争议所必需的最小记录可以继续保存

如果公开资源需要保留、转移或下架，应在注销前向创作者说明处理方式

用户可以通过 App 内的意见反馈入口或联系邮箱提交上述请求，OronBox 在完成必要的身份核验后 15 个工作日内答复，情况复杂需要延长时会说明原因和预计时限

## 9. 自行部署

自行部署者会独立控制其服务器中的数据，应自行说明运营身份、存储地点、日志、OAuth 配置和数据处理方式

OronBox 项目维护者无法访问或控制自行部署实例中的数据

## 10. 信息安全

官方服务应采取与项目规模和数据风险相称的措施，包括 HTTPS、OAuth state、短期登录票据、会话轮换、Token 加密、最小权限、访问控制、备份和日志脱敏

发生可能影响用户权益的安全事件时，维护者应尽快控制风险、撤销受影响凭证、保存必要证据，并在合理可行且依法需要时通知相关用户或机构

互联网服务不存在绝对安全，用户也应保护自己的设备、账号和授权凭证

## 11. 未成年人

OronBox 面向具有相应理解和操作能力的穿戴设备用户，不主动以未成年人为目标收集信息

未成年人应在监护人指导下使用账号授权、资源发布和可能影响设备的功能

## 12. 变更与联系

新增个人信息用途、扩大 OAuth 权限、扩大第三方提供范围或改变主要存储地点时，应更新本说明并在必要时重新取得确认

与官方在线服务有关的法律适用与争议解决按照《用户协议与免责声明》处理
